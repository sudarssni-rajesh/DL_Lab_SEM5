# DL_Lab_SEM5
# Single Layer Perceptron for Binary Classification

Implementation of a **Single Layer Perceptron** from scratch using Python for binary classification on the **Banknote Authentication Dataset** as part of the **CS3807 – Deep Learning Laboratory** course.

## 📌 Overview

This project demonstrates the implementation and analysis of a Single Layer Perceptron, including:

- Data exploration and preprocessing
- Perceptron implementation from scratch
- Training using the Perceptron Learning Algorithm
- Performance evaluation
- Visualization of learning behaviour
- Decision boundary visualization
- Learning rate comparison

The project also includes additional experiments on logic gates and XOR perceptron learning.

---

## 📂 Dataset

**Dataset:** Banknote Authentication Dataset

- Samples: **1372**
- Features: **4 numerical attributes**
- Classes: **2 (Authentic / Forged)**

Features:

- Variance
- Skewness
- Curtosis
- Entropy

## 🧠 Additional Experiments

### Logic Gates

Implementation of the Perceptron Learning Algorithm for:

- AND Gate
- OR Gate
- NOT Gate

Features:

- Weight updates after every iteration
- Decision boundary after every update
- Training analysis

### XOR Gate

Implementation of a perceptron for the XOR gate demonstrating the limitations of a single-layer perceptron.

Includes:

- Weight updates after every update
- Decision boundary after every update
- Convergence analysis
- Explanation of why XOR is not linearly separable
